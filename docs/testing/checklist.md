# 手動テストチェックリスト（yakumo-gui）

大きな変更の後やリリース前に通しで確認する項目。実施結果は test-log.md に日付付きで残す。
ID は test-log.md から参照するためのもの。項目を増やすときは各表の末尾に追加し、既存の ID は変えない。

## 前提
- テスト VM は OS 入りディスクのコピー（例: test-vm03.qcow2）を使う。空の qcow2 では起動・停止系のテストができない。
- 1 つの qcow2 を複数の VM で共有しない（同時起動でイメージが壊れる）。
- GUI は `qemu:///system` に接続できるユーザー（libvirt グループ）で起動する。

## VM 作成（CreateVM）
| ID | 手順 | 期待結果 |
|---|---|---|
| CR-01 | 正常な名前・2048 MB・2 vCPU・qcow2 を指定して作成 | 一覧に shutoff で現れる |
| CR-02 | `virsh dumpxml <name>` を確認 | `<features><acpi/><apic/>`、virtio ディスク/NIC、VNC（127.0.0.1）がある |
| CR-03 | 既存と同じ名前で作成 | "Domain already exists" で拒否 |
| CR-04 | 名前にスペースや `/` などを含める | 名前不正で拒否 |
| CR-05 | メモリ 255 MB または 32769 MB、vCPU 0 または 17 | 範囲外で拒否 |
| CR-06 | 拡張子だけ .qcow2 の raw ファイルを指定 | 拒否（マジックナンバー判定） |

## ライフサイクル
| ID | 手順 | 期待結果 |
|---|---|---|
| LC-01 | shutoff の VM で Start | running になり、VNC で起動画面が見える |
| LC-02 | ログイン画面まで起動してから Shutdown | ゲストが自分で停止し、数十秒〜1 分で shutoff になる |
| LC-03 | running の VM で Reboot | ゲストが再起動する（状態は running のまま） |
| LC-04 | running の VM で ForceStop | 即座に shutoff になる |
| LC-05 | VM の状態ごとのボタン | 状態に合わないボタンが無効化される（例: shutoff 中は ForceStop が押せない） |
| LC-06 | 失敗時の文言（例: virsh で先に止めた VM に Shutdown） | ダイアログに libvirt の理由文が出る |

## 削除
| ID | 手順 | 期待結果 |
|---|---|---|
| DEL-01 | running の VM で Delete | 確認ダイアログを出さず、稼働中である旨を表示 |
| DEL-02 | スナップショットが残る VM で Delete | 確認ダイアログを出さず、件数付きの理由を表示 |
| DEL-03 | 削除可能な VM で Delete | 確認ダイアログ → 一覧から消える。ディスクファイルは残る |

## スナップショット
| ID | 手順 | 期待結果 |
|---|---|---|
| SN-01 | shutoff の VM で名前を付けて Create | 一覧に現れ、Current（★）が付く |
| SN-02 | 名前を空または空白だけにして OK | 警告ダイアログ。キャンセルは無言で閉じる |
| SN-03 | running の VM で Create | RAM 込みで作成される（時間がかかり GUI が固まる: 既知問題） |
| SN-04 | Revert | 選んだスナップショットの状態に戻る |
| SN-05 | 子を持つスナップショットを Delete | 子が reparent され削除成功 |

|---|---|---|
| VNC-01 | running の VM で Console | 画面が描画される |

## ウォッチドッグ
| ID | 手順 | 期待結果 |
|---|---|---|
| WD-01 | `sudo pkill -9 -f 'guest=<VM名>'` でクラッシュさせる | 15〜25 秒以内に自動再起動。ステータスバーに通知、一覧が即時更新 |
| WD-02 | 4 回連続で落とす | 3 回まで再起動し、4 回目で諦め通知が 1 回だけ出る |
| WD-03 | 諦めた後に手動 Start → 再度落とす | 再び自動再起動する（再アーム） |
| WD-04 | GUI から Shutdown / ForceStop | ウォッチドッグは介入しない（勝手に再起動されない） |

## 状態更新
| ID | 手順 | 期待結果 |
|---|---|---|
| ST-01 | 何もせず待つ | 70〜90 秒ごとに一覧が更新される（コンソールに "timer fired"） |
| ST-02 | 一覧の行をクリック | 詳細パネルとボタンが最新状態になる（状態列は次の定期更新で反映） |
